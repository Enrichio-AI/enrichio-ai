# Enrichio 🚀

### AI-Powered SEO Content Generation for Shopify Stores

Enrichio helps Shopify merchants generate high-quality, SEO-friendly product content automatically using AI.

From product descriptions to meta titles and search keywords, Enrichio creates optimized content designed to improve product visibility, increase conversions, and save hours of manual work.

Built for modern Shopify brands that want scalable content generation without sacrificing quality.

## ✨ Features

* 🤖 AI-generated product descriptions
* 🔍 SEO-optimized meta titles & descriptions
* ⚡ Bulk content generation
* 🎯 Smart keyword optimization
* 🛍️ Shopify-native workflow
* 🧠 Brand-aware content generation
* 📈 Conversion-focused product copy
* 🔄 One-click regenerate & improve
